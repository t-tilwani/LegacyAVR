# Images

Screenshots and diagrams referenced by the main README. Add them here with these names, then remove the
comment markers around the matching image lines in `README.md` (and `Github Releases/README.md`):

| File | Content |
|---|---|
| `main-window.png` | Dashboard: Mixer or Output & Profiles tab with audio playing |
| `eq-dialog.png` | Custom EQ dialog with the response curve |
| `architecture.png` | Optional image version of the ASCII architecture diagram |

Before adding a screenshot, check it shows no personal information (Windows user name, device names you would
rather keep private, file paths, other open windows).
